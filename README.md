# One More Door

A solo push-your-luck dungeon game: open doors under the old keep, fight, grab materials, and walk home to grow your homestead.

- `index.html`: the homestead version (main game)
- `homestead.html`: same as index, kept so old links work
- `town.html`: the earlier town version
- `classic.html`: the earlier card-and-energy version

Each page is a single self-contained HTML file with no build step. Progress saves in your browser.
